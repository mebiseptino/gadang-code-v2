# Gadang.Code V2 - Minangkabau Tech Copilot
**Live:** https://gadgetkinipadang.web.id
**Tagline:** Coding Modern, Identitas Tetap Gadang

### The Problem
Gen Z in Padang wants modern coding gadgets but loses cultural identity. Existing AI tools don't speak Minang.

### Solution - Build for Your World
First coding gadget platform inspired by Rumah Gadang & Batik Minangkabau.

Features:
- **Uda AI Minang:** AI copilot 3 languages (ID | ENG | MINANG) - "Alam Takambang Jadi Guru"
- **Scan Desk & Batik AI:** Visual search using SAM 3.1
- **Single-Flight Pattern:** 99% API cost saving - $150 credits = 149K chats

### Built With Meta
- Llama 4 API for chat
- SAM 3.1 for detection
- Llama Image for Batik pattern
